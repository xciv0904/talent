# Career Lab 後續工作與交付邊界

## 本次已完成
- Phase 0：開發前程式碼盤點與 138 項舊測試基準。
- Phase 1：型別、純轉移、seed、條件、存檔、暫停與恢復。
- Phase 2：端到端 Career Life、年份、狀態、決策結果及起點快照。
- Phase 3：原六職業核心情境、結構化任務、產出與獨立主觀反思。
- Phase 4：多存檔、決策前分支、任務繼承、比較、個別刪除。
- Phase 5：來源證據、歷史版本、雙時間軸、成長、列印及 JSON 報告。
- Phase 6：與原路由整合；依使用者要求擴充到十二職業，包含製造、技術與第一線服務；回歸與瀏覽器驗收，細節見 `career-lab-qa.md`。

「已完成」指上述本機首版範圍，不代表已正式部署、已證實心理計量有效性或已經真實從業者審核。

## 第二階段（尚未完成）

1. **更多現場類型**：擴充既有職業庫中其他製造、維修、醫療、教育、公部門、創作等路線；先審核內容與資格脈絡，不只增加職稱卡片。目前有 32 種完整 Lab 內容與 100 種完整目錄職業；仍有細分類缺口，見 career-coverage-audit.md。
2. **職業專屬後期故事**：Year 5／7 目前採條件式共用模板並調整現場工作脈絡。應增加各職業特定的學徒、證照、輪班、帶班、管理、跨廠及資源條件，而非宣稱所有職涯相同。
3. **多種獨立任務與作品 rubric**：每職業目前一份多步驟教學任務。新增第二、第三份不同情境、專家範例及同儕檢視，才能增加跨情境信心；重做同題不等於新能力證據。
4. **更細緻的個人化**：已有原測驗全脈絡快照、能量起點、部分天賦／目標／反思條件及原結果連結。並未把每項偏好向量轉成完整模擬人格，也沒有量表驗證；先用實際使用測試改善可解釋性。
5. **現實實驗追蹤**：已連回原 20 分鐘體驗並匯入原反思；尚未新增外部作品上傳、從業者回饋、長期實驗計畫與完成證明。
6. **時長與內容可信度**：3–5／12–20／5–20 分鐘只是設計目標，尚未做使用者時長研究。虛構教學情境需請不同產業從業者審閱；不將任務比率當統計常模。
7. **資料規模與跨裝置**：首版本機 localStorage 同步，無帳號及雲端備份。大量人生／分析版本可能遇 quota；已有提示及 JSON 匯出還原。後續可先做容量管理／IndexedDB，再評估雲端成本與必要性。
8. **自動化瀏覽器回歸**：目前測試環境是 Vitest 純邏輯，另以瀏覽器實際驗收；尚未新增 Playwright 套件或 CI E2E。後續可在獨立測試瀏覽器加入全流程及跨裝置矩陣。
9. **可選 AI 擴充**：目前完全沒有 AI 劇情或評分。若未來加入，必須為可選功能、區分規則與模型判斷、有隱私同意，核心模式仍免費且不需 API。
10. **部署**：尚未 commit／push／正式發布；沿用現有 Vercel 專案。發布前先完整跑測試與 build，再驗證正式 route、assets 與 CSP。
