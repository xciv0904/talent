## Context ladder

1. **Level 1 — Universal:** concrete events such as a stuck task, mixed opinions, many details, or learning something unfamiliar. This is the default.
2. **Level 2 — Common activity:** learning, travel, daily arrangements, practice, and shared activities. Use only when Level 1 would remove necessary context.
3. **Level 3 — Workplace:** customer, colleague, shift, or work setting. Allowed only when an occupational follow-up truly measures work behavior.
4. **Level 4 — Specialized workplace:** project, stakeholder, cross-department, proposal, formal meeting, specification, delivery, or project timeline. Prohibited in Quick Discovery.

After remediation, Quick Discovery contains no Level 4 wording and requires no formal work, project-management, office, customer-service, or people-management experience.

## Major before and after examples

1. **SJT01** — `一個重要專案突然卡住，但原因還不明確。` → `一件你正在做的重要事情突然卡住，而且你還不知道原因。`
2. **SJT05** — `跨部門合作的需求仍很模糊，而且彼此立場不同。` → `幾個人要一起完成一件事，但需要做到什麼還很模糊，大家的立場也不同。`
3. **FC02 option** — `提案被關鍵人物採納的機會` → `重要想法被採納的可能`
4. **FC04** — `在一個成熟團隊裡，你最想持續承擔哪種責任？` → `幾個人長期一起做事時，你最願意持續承擔哪種責任？`
5. **BEH04** — `在團隊討論裡，哪一種貢獻最常由你自然做出？` → `幾個人一起討論重要事情時，哪一種貢獻最常由你自然做出？`
6. **ENG09** — `哪種會議任務即使表現不差，結束後仍最容易疲累？` → `和別人一起處理重要事情時，哪種負責內容即使表現不差，事後仍最容易疲累？`
7. **INT03 option** — `策略取捨與資源配置` → `困難取捨與有限時間安排`
8. **ENV02 option** — `經常串聯不同專業與部門` → `經常串聯不同專長的人`
9. **VAL04** — `面對升遷機會，你最不希望犧牲的是？` → `選擇下一個重要機會時，你最不希望犧牲的是？`
10. **VAL05** — `回顧一段理想工作經驗，你最希望它留下什麼？` → `回顧一段讓你滿意的經驗，你最希望它留下什麼？`
